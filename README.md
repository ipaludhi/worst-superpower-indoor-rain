One line inventing the most useless superpower, for make.fun's "Worst Superpower" bounty ($2 in USDC, winner-takes-all).

> I can summon rain indoors, but only directly above my own head, one drop at a time.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
